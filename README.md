#Bioinformatics Stronghold
酵素配列の最適化につながりそうな問題を解いた。
A. 基本8問
- DNA(塩基を数える)、RNA(転写)、REVC(逆相補鎖): 最初の3問
- GC(GC含量): FASTAを読む。
- HAMM(ハミング距離): 2本の配列の違いを数えるアライメントの前段階。
- PROT(翻訳): コドン表でRNAをタンパク質に直す。
- SUBS(モチーフの位置): DNA中の決まった並びを探す。
- FIB(漸化式): 再帰的な処理の練習。
B. 応用4問
- CONS(コンセンサスとプロファイル): 複数の配列を位置ごとに集計する。
- ORF(読み枠を探す): DNAの6つの読み枠からタンパク質になりうる部分を探す。
- PRTM(タンパク質の質量): アミノ酸ごとの値の表を使って質量を計算する。
- MPRT(タンパク質モチーフ): UniProtからプログラムで配列を取り、正規表現でモチーフを探す。
